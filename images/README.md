# FoodSense Image Analysis Samples

This folder contains fresh and spoiled produce images for testing the Hugging Face Space Image Analysis tab.

Use the `fresh_*.jpg` files for expected fresh/high-quality outputs and the `spoiled_*.jpg` files for expected spoiled/low-quality outputs. The strongest matches for the current models are banana, apple, mango, tomato, and strawberry because those classes overlap with the local vision model labels.
